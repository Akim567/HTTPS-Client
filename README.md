# HTTPS Client

Базовый шаблон Java-приложения для выполнения задания из
[`assignment.md`](assignment.md).

Функциональные пункты задания пока не реализованы.

Для запуска откройте проект в IntelliJ IDEA и запустите метод `main` из
класса `netdiag.Main`.

## Структура

```text
src/netdiag/
├── Main.java
├── cli/            # аргументы командной строки
├── url/            # разбор URL и модель адреса
├── dns/            # DNS-резолвинг
├── connect/        # установка TCP-соединения
├── http/           # формирование и разбор HTTP-сообщений
└── diagnostic/     # модель и печать результата
```
